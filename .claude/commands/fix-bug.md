Use ultrathink para diagnosticar e corrigir o bug descrito.

Processo:
1. Entenda completamente o problema antes de tocar em qualquer código
2. Trace o fluxo de dados do início ao fim
3. Identifique onde exatamente a lógica quebra
4. Considere pelo menos 3 abordagens diferentes para a correção
5. Escolha a mais simples e segura
6. Implemente a correção
7. Verifique se a correção não quebra nada relacionado

Nunca aceite a primeira solução óbvia — pense fundo primeiro.
