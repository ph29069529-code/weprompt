Execute um QA completo da plataforma WePrompt.

Verifique cada fluxo:

FLUXO PÚBLICO:
- Homepage carrega sem erros?
- Catálogo /solucoes lista as soluções?
- Página de solução /solucoes/[id] funciona?
- Perfil de criador /criadores/[id] funciona?
- Páginas /precos, /privacidade, /termos carregam?
- Login e cadastro funcionam?

FLUXO CRIADOR:
- Dashboard /dashboard/criador carrega com dados reais?
- Formulário de nova solução funciona (Agente IA e Prompt Pack)?
- Upload de imagem funciona?

FLUXO EMPRESA:
- Dashboard /dashboard/empresa mostra soluções adquiridas?
- Botão "Abrir Workspace" navega corretamente?
- Workspace carrega o agente?

FLUXO ADMIN:
- Dashboard /dashboard/admin carrega todas as 11 abas?
- Aprovar/rejeitar soluções funciona e envia email?

Para cada item: status (OK/ERRO) e descrição do problema se houver.
