# WePrompt — Brand Reference

## Identity
WePrompt is the first AI solutions marketplace in Latin America, focused on the Brazilian market.

**Logo:** `/public/logo.png` (also available: `logo-dark.png`, `logo-light.png`, `logo-icon.png`)
Use `<img src="/logo.png" alt="WePrompt" style={{ height: 32 }} />` — the logo contains the wordmark, no extra text needed.

## Color Palette

### Accent (Indigo)
| Token | Value | Use |
|---|---|---|
| `accent.DEFAULT` | `#6366F1` | Primary CTAs, highlights, icons |
| `accent.hover` | `#4F46E5` | Hover state for accent elements |
| `accent.muted` | `rgba(99,102,241,0.1)` | Subtle accent backgrounds |
| `accent.border` | `rgba(99,102,241,0.25)` | Accent-tinted borders |
| `accent.glow` | `rgba(99,102,241,0.15)` | Glow effects, shadows |

### Neutrals
| Token | Value | Use |
|---|---|---|
| `bg.dark` / `text.primary` | `#0A0F1E` | Dark brand color, headings |
| `bg.secondary` | `#F8F9FB` | Alternate section background |
| `bg.tertiary` | `#F3F4F6` | Cards, subtle fills |
| `text.secondary` | `#6B7280` | Body text, subtitles |
| `text.muted` | `#9CA3AF` | Timestamps, meta |
| `border.DEFAULT` | `#E5E7EB` | Default borders |

### Semantic
| Name | Value | Use |
|---|---|---|
| Indigo muted bg | `#EEF2FF` | Icon backgrounds, status badges |
| Dark text accent | `#4F46E5` | Badge labels on light bg |

## Typography
- **Font:** Inter (system fallback: -apple-system, BlinkMacSystemFont, sans-serif)
- **Headings:** `fontWeight: 800`, `letterSpacing: -0.03em` to `-0.04em`
- **Body:** `fontWeight: 400`, `lineHeight: 1.6–1.7`
- **Labels/caps:** `fontWeight: 700`, `letterSpacing: 0.08em–0.12em`, `textTransform: uppercase`, `fontSize: 12–13px`

---

## Spacing
- Section padding: `80px 48px` (desktop), `80px 24px` (mobile via `.section-pad`)
- Max content width: `1100px` (sections), `1200px` (footer/navbar)
